Brick SPARQL playground

Button-driven tutorial for read-only SPARQL against a Brick model. Inventory the mechanical system, see which Open-FDD roles the graph can satisfy, then copy a local Python command.

Who crunches faults? This server only answers SPARQL + timeseries JSON. scripts/analyst_client.py on your laptop pulls those points and runs open_fdd.rules.run_rule locally (that is what printed FAULT 10.5 … in your terminal).
